# V4.1 Phase5 — Shot Production Runtime Contract

## Previous Final Policy

- `NONE`: 不使用上一 Final。
- `STATE_REFERENCE_ONLY`: 只继承 Identity / Space / Lighting / Props / Action State；**不上传上一 Final 作为视觉主参考**。
- `HIGH_PRIORITY_VISUAL_CONTINUITY`: 必须存在并上传上一 Shot Final，作为最高优先级视觉连续性参考。

因此：切镜不再默认参考上一张 Final。

## Frozen Moment

IMAGE PROMPT 只描述 Shot 的 Start Frame / Frozen Moment。
`shot_delta` 只进入 VIDEO PROMPT。

这样避免：
“准备起跳” → IMAGE 已经跳起。

## ChatGPT Handoff

每个 Shot 生成 `CHATGPT_HANDOFF.md`，明确：

- `SHOT_PROMPT_ONLY`
- 只输出 Production Progress / IMAGE PROMPT / VIDEO PROMPT
- 不调用图片生成
- 不重新导演

用于避免上一轮刚生成图片后，下一 Shot 指令再次触发图片生成。

## Runtime

```text
GENERATE_CURRENT_SHOT_PACKAGE
→ WAIT_FOR_IMAGE_APPROVAL
→ WAIT_FOR_VIDEO_APPROVAL
→ Next Shot: GENERATE_CURRENT_SHOT_PACKAGE
→ Scene End: PLAN_CURRENT_SCENE
→ Episode End: EPISODE_COMPLETE
```
