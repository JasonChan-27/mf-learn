# V4.1 Phase6 — Pure Prompt Compiler Contract

## 唯一原则

```text
Director State
→ Prompt Compiler
→ Natural Language Prompt
```

Prompt Compiler 是“翻译器”，不是导演。

## Compiler 可以做

- 格式化
- 字段排序
- Markdown 结构
- 把锁定 JSON 字段翻译成 IMAGE / VIDEO Prompt
- 加入固定的执行边界说明
- 生成 Prompt hash / source-state hash

## Compiler 禁止做

- 改 Shot 数量
- 改 Camera
- 改 Coverage
- 改 Composition
- 增删可见角色
- 推测 Missing State
- 创作 Frozen Moment
- 创作 Shot Delta
- 改 Previous Frame Policy
- 自动把微动作拆成新 Shot

缺字段必须 FAIL，不允许补默认导演内容。

## 新产物

每个 Shot Package 新增：

```text
PROMPT_COMPILATION_MANIFEST.json
```

记录：

- `compiler_mode = PURE_STATE_TRANSLATION`
- `creative_decision_allowed = false`
- State SHA256
- IMAGE Prompt SHA256
- VIDEO Prompt SHA256
- 锁定字段列表

用于以后精确判断问题属于：

```text
Director Planning
State Compiler
Image / Video Model
```
