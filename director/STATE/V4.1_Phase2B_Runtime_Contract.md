# V4.1 Phase2-B — Build / Reset Runtime Contract

## Reset

```bash
python3.12 tools/run.py EP002 --reset
```

只允许：

```text
Build Episode Context
Create Director State Index
Create Runtime State
Create Scene Skeletons
```

禁止：

```text
Create Shot Plan
Create Shot State
Choose Camera
Choose Coverage
Generate Prompt
Create production/ShotXX
```

Reset 后：

```text
Scene01 = PLANNING
shot_count = 0
next_action = PLAN_CURRENT_SCENE
```

## Scene Planning

```bash
python3.12 tools/run.py EP002
```

若 `next_action = PLAN_CURRENT_SCENE`，只生成：

```text
SCENE_PLANNING_REQUEST.md
Scene_Director_Plan_TEMPLATE.json
```

不得生成 Shot Package。

Python：
