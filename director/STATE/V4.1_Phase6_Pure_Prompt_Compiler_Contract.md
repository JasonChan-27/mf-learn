# V4.1 Phase6 — Pure Prompt Compiler Contract

## 核心原则

```text
Locked Shot State + Previous Frame Policy
→ Pure Prompt Compiler
→ Prompt Contract QA
→ prompt files
```

Prompt Compiler 不得进行导演创作。

## Compiler 允许

- 字段格式化
- 中文/英文提示结构化
- 把 State 枚举转换为可读文本
- 输出固定负面约束
- 输出 Previous Frame Policy
- 输出资产清单引用

## Compiler 禁止

- 改 Camera
- 改 Coverage
- 改 Composition Intent
- 改角色可见性
- 新增 Shot 动作
- 创造 Frozen Moment
- 推测 Start State / End State
- 为了“画面更丰富”新增运镜
- 根据 Prompt 自己决定 Scene End

## IMAGE / VIDEO 强分离

IMAGE 只能包含：

```text
Start State
Frozen Moment
Physical Boundaries
Forbidden Advanced States
```

VIDEO 才包含：

```text
Shot Delta
Camera Motion
End State
Timing
```

Prompt Contract QA 会阻止 `shot_delta.primary_action` 泄漏到 IMAGE Prompt。

实际 Gate 覆盖全部 VIDEO-only State：Primary / Secondary Action、Performance、
Timing、Camera Motion、Movement Reason 与 End State。

Prompt Compiler 不读取 `DirectorDecision`。该文件只供 Director QA、问题归因和
未来重新规划使用。

每次成功编译必须生成 `PROMPT_COMPILATION_MANIFEST.json`，记录不可变 Prompt
Source State 与所有 Prompt 文件的 SHA256。
