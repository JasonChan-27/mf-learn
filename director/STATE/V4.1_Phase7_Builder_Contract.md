# V4.1 Phase7 — Deterministic Shot Package Builder Contract

## 唯一职责

```text
Locked Runtime + Locked Scene State + Locked Shot State
→ Pure Prompt Compiler
→ Required Asset Resolution
→ Versioned Shot Package
→ Deterministic Runtime Advance
```

Builder 不进行导演创作。

## 权威输入

- `Runtime_State.json`：当前 Scene、Shot 和 `next_action`。
- `Scene_State.json`：Scene 必须已经通过 Director QA，`plan_status = LOCKED`。
- `ShotXX-XX_State.json`：Prompt 与 Package 的唯一镜头执行真相。
- `assets/AssetRegistry.json`：资产 ID、源路径、SHA256 和大小的唯一映射。
- 上一 Shot Final：仅在锁定 Policy 要求时读取。

Builder 禁止读取 `DirectorDecision` 重新解释“为什么”，也禁止读取 Confirmed Script、
Scene Director Plan 或 Prompt 文本补充 Shot 设计。

## 资产合同

Builder 只复制 `Shot_State.required_assets.asset_ids` 中的资产。

以下情况全部进入 `NEED_ASSET`：

- Asset ID 未登记；
- Registry 路径越出项目根目录；
- Registry 已登记但源文件不存在；
- 文件大小与 Registry 不一致；
- SHA256 与 Registry 不一致。

Python 只报告缺口，不选择相似资产，不从旧 Build 目录寻找替代副本。

## Previous Frame Policy

- `NONE`：不复制上一 Final。
- `STATE_REFERENCE_ONLY`：只执行状态连续性说明，不复制上一 Final，避免切镜构图被绑死。
- `HIGH_PRIORITY_VISUAL_CONTINUITY`：上一 Final 必须存在并复制进 `upload/`。

Policy 来自已经锁定的 Shot State，Builder 不修改它。

## Package 输出

```text
episodes/<EP>/production/<Scene>/<Shot>/
├── CURRENT_PACKAGE.json
├── <Shot>_Final.png              # 用户批准后产生
├── <Shot>_Video.<ext>            # 视频批准后可产生
└── packages/
    ├── v001/
    ├── v002/
    └── ...
```

每个版本包含：

```text
prompt.md
IMAGE_PROMPT.md
VIDEO_PROMPT.md
CHATGPT_HANDOFF.md
PROMPT_COMPILATION_MANIFEST.json
required_assets.json
UPLOAD_MANIFEST.json
PACKAGE_MANIFEST.json
upload/
```

`PACKAGE_MANIFEST.json` 必须声明：

- `builder_mode = DETERMINISTIC_STATE_BUILDER`
- `creative_decision_allowed = false`
- `reads_director_decision = false`
- `state_authority = Shot_State.json`
- Package 输入 hash
- 每个输出文件 hash

## 版本与幂等

- 相同锁定 State、相同资产内容、相同 Previous Final：复用当前完整 Package。
- 当前 Package 缺文件或 hash 不一致：创建下一版本，不覆盖旧目录。
- 锁定输入发生变化：创建下一版本，不覆盖旧目录。
- Package 完整提交后才把 Shot 更新为 `PROMPTED`。

## Runtime

成功：

```text
GENERATE_CURRENT_SHOT_PACKAGE / NEED_ASSET
→ WAIT_FOR_IMAGE_APPROVAL
```

资产缺口：

```text
→ ASSET_REQUIREMENT.md
→ NEED_ASSET
```

Builder 不批准图片，不批准视频，不决定下一 Shot；这些仍由 Production Runtime 执行。
