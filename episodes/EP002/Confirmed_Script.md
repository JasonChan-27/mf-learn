# EP002《猫咪吃播大作战》

## 故事核心

小南外出取快递，三只猫从“舍不得主人”的戏精状态迅速恢复本性。随后，它们发现小南最近似乎在研究吃播，误以为主人遇到了困难，于是决定主动帮忙。

在阿诺的带领下，三只猫尝试进行第一次“猫咪吃播”，却阴差阳错拨通了小南朋友小佳的视频电话，引发尴尬乌龙。

最终小南发现它们只是想帮助自己，理解了它们的用心，并奖励它们猫咪蛋糕。但小帅因为太贪吃，又制造了新的笑点。

# Scene 01 玄关｜离别演技

**地点：玄关**

小南准备出门。

三只猫发现主人要离开。

瞬间，气氛改变。

刚才还各自玩耍的三只猫，立刻进入“舍不得主人”的表演状态。

大漂亮第一个冲过去。

它跳进小南怀里，表情认真又担忧。

**大漂亮：**

主人……

外面的世界竞争太激烈了。

你一定要注意安全。

小南愣了一下。

小帅紧跟其后。

它抱住小南的腿，声音颤抖，仿佛马上要失去主人。

**小帅：**

主人……

如果你回不来了……

我们该怎么办呀？

大漂亮、小帅表情悲伤。

阿诺慢慢走过来。

它端正坐在小南面前，神情严肃。

**阿诺：**

主人放心。

我会照顾好他们两个。

小南看着三个猫咪。

感动了一秒。

随后忍不住笑。

**小南：**

你们三个……

小南摸了摸大漂亮的头。

**小南：**

我只是出去取个快递。

很快回来。

空气安静。

三只猫表情瞬间僵住。

大漂亮慢慢从小南怀里下来。

小帅松开爪子。

阿诺保持严肃坐姿。

小南打开门。

**小南：**

在家乖一点。

随后关门离开。

**小帅：**

**小帅：**

**阿诺：**

我吃不惯。

**小帅：**

嗯？

**小帅：**

嗯……

就是这个味！

它坐起来继续吃。

随后余光看到阿诺。

动作慢慢停住。

阿诺正在认真剪自己的爪子。

小帅愣住。

**小帅：**

等等……

你拿剪刀……

修自己的脚丫子？

阿诺抬头。

一脸得逞满意的样子。

**阿诺：**

不然呢？

小帅震惊。

**小帅：**

你怎么能这样？

坏大个！

阿诺假装不好意思。

**阿诺：**

我这不是为了让你早点吃上吗。

我那份冻干也是你的。

# Scene 05 餐厅｜第一次猫咪吃播

餐桌已经准备好。

大漂亮和小帅坐在桌子一侧，面对手机。

阿诺坐在另一侧。

一小盘冻干。

发现差距。

**小帅：**

等等。

**小帅：**

**大漂亮：**

都是你们喜欢吃的。

**阿诺：**

第一步……

连接用户。

三只猫期待等待。

视频接通。

小佳看到三只猫。

**小佳：**

咦？

小南？

干嘛呢？

三只猫盯着屏幕。

**小帅：**

她会喜欢冻干吗？

阿诺立刻打断。

**阿诺：**

别乱说。

要礼貌。

阿诺示意开始。

面对手机。

**阿诺：**

看一下我们的薄荷小鱼饼干。

它添加了三文鱼、茶多酚等天然成分。

最重要的是……

有薄荷！

口感酥脆。

每年复购用户突破……

阿诺停顿。

认真思考。

**阿诺：**

一百万！

小帅马上进入状态。

拿起冻干。

**小帅：**

我的冻干。

无添加。

保留鸡胸肉原本味道。

原生好口感，安心又美味。

吃了以后……

可以健康成长哦！

旁边的大漂亮疯狂配合。

**大漂亮：**

真的吗？

我也想吃！

**三只猫：**

喵！

喵！

喵！
